    Implemented safeguards

    • Help overrides the illustrative score.
    • Acknowledgement never clears an emergency.
    • Stale or invalid data cannot display green.
    • Forecasts cannot reduce the baseline warning.
    • Small crew counts are withheld.
    • Crew fixtures never read individual badge sessions.

    Validation boundary

    Software tests exercise synthetic alert and failure scenarios. No clinical performance, full-shift battery life or field-device reliability is claimed.

    Before field deployment

    Expert review, reference measurements, hardware tests, worker language review, consent and appropriate site/ethics approval.

    Exaclim uses UI SDK primitives for interactive controls. The research model remains explicitly illustrative.
